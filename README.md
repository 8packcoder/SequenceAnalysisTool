# 🧬 Sequence Analysis Tool

A lightweight, Java-based GUI application for analyzing DNA and RNA sequences — built to support students, educators, and researchers in the field of bioinformatics and biotechnology.

---

## 🚀 Features

- 🔹 **DNA → RNA Transcription**
- 🔹 **RNA → Protein Translation**
- 🔹 **Reverse Transcription**
- 🔹 **Motif Finding** (search for specific patterns in sequences)
- 🔹 **Sequence Alignment**

---

## 🧠 What This Project Teaches

- Core bioinformatics operations and logic
- GUI design using **JavaFX**
- Object-oriented programming in **Java**
- Handling biological data and algorithmic processing
- Version control using **Git** and **GitHub**

---

## 🛠️ Tech Stack

- **Language:** Java  
- **GUI Framework:** JavaFX  
- **Tools:** IntelliJ IDEA, Git, GitHub
  
---

## 🧪 Use Cases

- Helping **biotech students** understand sequence analysis
- Creating simple tools for **DNA/RNA/protein conversion**
- Performing **basic research operations** without needing complex bioinformatics software
